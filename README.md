# وب‌سایت توانا

یک وب‌سایت استاتیک با HTML، CSS و JavaScript.

## اجرا

فایل `index.html` را در مرورگر باز کنید. برای توسعه، می‌توانید پوشهٔ پروژه را در VS Code باز کرده و از افزونهٔ Live Server استفاده کنید.

## ساختار پروژه

- فایل‌های HTML در ریشهٔ پروژه قرار دارند.
- فایل‌های CSS، JavaScript و تصاویر در پوشهٔ `assets/` نگهداری می‌شوند.
- تصاویر استادان و دوره‌ها در زیرپوشه‌های جداگانهٔ `assets/images/` قرار می‌گیرند.
